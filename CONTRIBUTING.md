# Contributing to BlazeForms

Thanks for considering a contribution!

- **How we build** — every standard (naming, tests, accessibility gates, commit format) is in [AGENTS.md](AGENTS.md). It is written for humans and coding agents alike; read it before your first PR.
- **What we're building and why** — scope, phasing, and locked decisions are in [docs/PRD.md](docs/PRD.md). Check the decision log before proposing a direction change.
- **Sign-off** — this project uses the [Developer Certificate of Origin](https://developercertificate.org/). Add `Signed-off-by` to each commit (`git commit -s`).
- **Bugs** — open an issue with a minimal repro; a PR that starts with a failing regression test is the fastest path to a merge.
